CloudTimer.app

CloudTimer is a free, web-based synchronized countdown timer. All users are connected to the same countdown timer simultaneously.

A HOST begins the session and shares the session ID code. A VIEWER logs on to the same timer session. The host can then start the timer and the timer display is synchronized across the network. Multiple viewers on multiple devices can be connected simultaneously.
